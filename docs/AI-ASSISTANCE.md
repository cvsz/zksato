# AI assistance architecture

## Allowed uses
Read-only market/context summaries, approved-news summaries, scanner explanations, portfolio questions, anomaly summaries, strategy research, documentation and test assistance.

## Boundary
AI output is untrusted advisory data. Any proposed action must become a typed deterministic proposal and pass normal policy/authorization. AI cannot receive broker secrets, live approval authority, or direct broker mutation tools.

## Audit
Record model/provider/version where material, prompt/input provenance as policy permits, output summary/hash, human decision, and resulting deterministic action if any.
