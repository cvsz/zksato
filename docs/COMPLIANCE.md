# Compliance and provider obligations

This project must operate within applicable broker, exchange, Settrade API/data, account, and jurisdictional requirements.

## Engineering implications
Preserve auditability, environment/account authorization, provider rate/data-use restrictions, credential confidentiality, approved automation permissions, and change-control evidence where required.

## Release gate
Before production use, confirm current broker/Settrade permissions and operational terms independently. Repository code/documentation must not be treated as legal or broker authorization.
