# Authors and contributors

zksato is maintained in the `cvsz/zksato` repository.

Primary repository owner: `cvsz`.

Git history remains the authoritative contributor record. Contributions may include human-authored and AI-assisted work; AI-assisted contributions must follow `AGENTS.md` and `docs/AI-ASSISTANCE.md` and remain reviewable, attributable through Git history, and subject to the same validation requirements as other changes.
