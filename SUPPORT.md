# Support

For defects and feature requests, use GitHub Issues with the provided templates. For security vulnerabilities, follow `SECURITY.md` and do not publish secrets or exploit details in a public issue.

When reporting a trading defect include mode (`paper`/`sandbox`/`live`), sanitized configuration, symbol/contract, timestamps/timezone, expected behavior, observed behavior, order IDs with sensitive values removed, and relevant audit/log excerpts.
