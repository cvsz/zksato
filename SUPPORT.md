# Support

## Scope
zksato is a risk-first SET/TFEX automation and research platform. Support covers repository usage, paper mode, development, CI/CD, deployment preparation, Settrade UAT integration, and operational troubleshooting.

## Before requesting help
1. Read `README.md` and `docs/INDEX.md`.
2. Check `docs/TROUBLESHOOTING.md`, `docs/FAQ.md`, and `docs/OPERATIONS.md`.
3. Reproduce in `paper` or authorized UAT; never reproduce a defect by enabling unrestricted live execution.
4. Remove credentials, account identifiers, PINs, tokens, cookies, and broker session material from logs.

## Where to report
- Bugs: GitHub Bug Report issue form.
- Feature proposals: Feature Request.
- Documentation gaps: Documentation issue form.
- Incidents: Incident issue form for sanitized operational incidents.
- Security vulnerabilities: follow `SECURITY.md`; do not disclose exploitable details or credentials in a normal issue.

## Support boundary
Repository maintainers cannot certify broker permissions, exchange calendars, legal suitability, production infrastructure, or financial outcomes. Autonomous live-money execution remains forbidden by repository policy.
