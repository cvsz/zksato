# Skill: operator dashboard

## Workflow
Design around operator decisions: mode/status → feed freshness → account/risk → signals → orders/fills → positions/P&L → audit/alerts.

## Rules
Paper/sandbox/live must be unmistakable. Synthetic data must be labeled. Destructive/money-moving actions require server authorization and confirmation. Secrets never enter browser bundles.

Validate responsive, error, empty, stale, loading, and reconnect states.
