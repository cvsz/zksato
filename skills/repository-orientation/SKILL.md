# Skill: repository orientation

## Use when
Starting any non-trivial zksato task.

## Workflow
1. Read `AGENTS.md`, `README.md`, `docs/INDEX.md`, `ROADMAP.md`, `docs/FEATURE-MATRIX.md`.
2. Locate affected modules/tests/docs.
3. Read relevant agent and skill playbooks.
4. Identify safety invariants and current implementation status.
5. Inspect CI and recent changes if the task follows prior work.

## Output
A scoped change plan with affected files, risks, tests, docs, rollout, and rollback.
